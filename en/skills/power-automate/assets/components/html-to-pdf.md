# Generate a PDF from HTML (file storage)

> **File**: `html-to-pdf.json` · **Frequency**: occasional · **Maturity**: designed [unverified]: generated, never returned by the designer
> **Depends on**: `export-csv-file` (same folder); `Linhas_html`; Microsoft cloud file storage connector (connector id in the JSON)

## Purpose

Writes the temporary HTML, converts it to PDF (`ConvertFile`), deletes the HTML even if the conversion fails, denies if the PDF did not come back, writes the PDF, creates the link and responds.

## When to use / when not to use

**Use**

- Simple pages generated by `Select` + `join`.

**Do not use**

- A large document: the converter accepts up to 2 MB per file.

## Where to paste

Inside `Caso_pdf` of `Switch_formato`, after `Linhas_html`.

## Inputs and outputs

**Reads**

- `body('Linhas_html')`: list of HTML fragments (a previous `Select`).

**Exposes**

- PDF file in the output folder and a response with `url`.

## Parameters to change

| Item | Value in the JSON | Replace with |
|---|---|---|
| `Linhas_html` | `Select` of fragments | the action that produces the HTML of each item |
| `pastaSaida` | `CONFIG` | folder |
| limit | 2 MB | adjust the message if the converter changes |

## runAfter

The root depends on `Bloco_filtros`. `Limpar_html` depends on `Converter_pdf` on `Succeeded`, `Failed`, `Skipped`.

## Pitfalls

- `Limpar_html` also runs when the conversion fails: it is a deliberate absorption so no HTML is left behind.
- `Se_pdf_falhou` tests whether `body('Converter_pdf')` came back empty; that test handles the connector failure, and the message tells the user to reduce the set.
- A `Failed` action inside the `Try` marks the `Try` as `Failed` even if handled later: finish with `Terminate` (the denial already terminates), or the `Catch` fires.
- The HTML must declare `<meta charset="utf-8">`.
- A fixed-width identifier (e.g. a barcode) in WDL is only possible with a fixed input length (no loop); outside that case, use an Office Script or an external service.

## Variations

- Without conversion (HTML only): skip `Converter_pdf` and return the HTML link.
