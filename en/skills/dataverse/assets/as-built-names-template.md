# Dataverse as-built names

Contract of names **from the real environment**. Every screen and every flow reads this file before
writing any formula. The data dictionary, the creation script and the plan **lose** to it.

> Copy this template to the `nomes_as_built` path in `power-platform.config.json`. **Part A** can be
> generated by `skills/dataverse/scripts/extrair-nomes-as-built.py` (mark it "generated -- do not
> edit"); **part B** is written by hand. A name or type not read stays `?`: never copy it from the dictionary.

## How to update

1. Redo the export (`references/as-built-names.md` §3).
2. `python <skill-folder>/scripts/extrair-nomes-as-built.py <export.json> --prefixo <prefix>_ --saida <this file>` -- `0 error(s)`.
3. Review the `diff` in Git: every changed line is a formula or a flow to re-check.
4. Update the date in the header.
